# Where Incremental Planning Goes Off Course

Milestone key: working-model-experiment.
Branch: milestone/working-model-experiment-statement-scope.

## Purpose

Find out whether observing an incrementally developed plan can reveal where
understanding goes wrong, and whether a restrained challenge helps the planner
diagnose the problem and choose an appropriate correction.

The experiment's result is the evidence and its evaluation. A correct final
plan, adopted domain model or product implementation is not the deliverable.

## Initial team actions

1. Agree one consequential planning task and the common evidence available.
2. Observe a planner developing an action list into a more concrete plan,
   without substantive intervention.
3. Observe a fresh planner doing the same task, with restrained challenges
   when a reviewer identifies a consequential problem.
4. Examine the histories, diagnoses and changed actions against the evidence.
5. Report whether this experimental approach produced useful insight.

## Planning still to do

The owner and advisor develop the experiment together. The foreman facilitates
its agreed execution; it is not asked to invent the hypothesis or choose a
replacement purpose.

We must select the common task, specify how incremental refinement is maintained,
decide what observations would bear on the question, and review the protocol
before launching participants.

Further detail belongs to later planning increments. Each increment should say
what became clearer and which choices remain open.
