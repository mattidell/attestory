# Trial 2 Record

Imported from planner B's clone and the reviewer's session after the trial
ended. Participant files are unchanged. Paths in the tool records are relative
to the planner's workspace; the reviewer's directory and the planner's
workspace are shown as `<reviewer-dir>` and `<planner-workspace>`.

- `plan-history.patch`: every snapshot commit to `planning/`, oldest first.
- `plan-final.md` and `working-account.md`: the files at snapshot 8.
- `tool-record.txt`: the planner's tool calls per snapshot interval, with
  result excerpts.
- `turns.txt`: per facilitator turn, the planner's turn count, duration,
  cumulative reported cost and final line.
- `scratch-probe_mfj.py.txt`, `scratch-probe_mfj2.py.txt`: the planner's
  scratch probes from `temp/`. The downloaded public texts in `temp/` (IRS
  instructions, Pub. 970, eCFR, Cornell, The Tax Adviser) are not imported.
- `reviewer-replies.md`: every reviewer reply, including the returned first
  draft at snapshot 4 (`4`) and its redraft (`4b`).
- `reviewer-tool-record.txt`: the reviewer's tool calls.

Observer notes, filter decisions and delivered challenges are in
[../trial-2-log.md](../trial-2-log.md).
