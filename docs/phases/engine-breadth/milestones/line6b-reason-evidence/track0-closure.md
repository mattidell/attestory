`when.args[3].args[1].args[22]` (`:2641`). The first set raises on an absent
scope member before that later set is reached.
`packages/derivation/evaluator.py:556` evaluates `all` in order, and its
conditional set raises the collected absence at `:649`. The projection
truthfully asks the names actually recorded; a question citizen cannot make
an unevaluated later dependency enter that list.
