Source: HEAD `470da6b0` on `milestone/line16-next-step-2025`. The ratified
comparison line is `origin/main` at `b9d529f7`; the branch was 0 behind and
1 ahead, and not spent. Published baseline: core v108, registry v106, release
v106. This is a builder unit (design, no build). Nothing under `packages/` or
`tests/` changed. All lists are synthetic `demo.*` acts. Each runs through
`live_coordinate_run` and the real presentation projection, using the same
`recorded_replay.saved_output` path the replay uses.

**Result: STOPPED for the owner.** The smallest design that meets both parts
of the scope needs a new content schema and a projection contract that no
accepted ADR covers. It is drafted, not filed, in [adr-draft.md](adr-draft.md).
The design is proven on a scratch build and a full-surface replay. If the
owner accepts it, the Track 1 scope is at the end of this note.

## 1. What the saved page says today (core v108)

[probe.py](probe.py) produced `probe-v108.json` (not kept; rerun the probe
to regenerate it), which covers
26 lists:

- all fifteen ways Exception 1 can fail on a single return that requires
  Schedule D and has no sale (`fails/single/01`–`15`; each bit is one
  criterion answered no);
- the four recorded targets (v82 honest lists);
- the joint and separate required neighbours;
- the personal-loss case (`exception1_personal_loss_8949`);

also records the question cards, the named questions, the recorded answers,
and every field's value.

### Where each text comes from

| Drawn text | Source |
| --- | --- |
| "This line has no result.", "Why:", "See the question and affected lines above" | Page (`renderLine`). The link is drawn for every reason a `questionRefs` entry points at. |
| Question sentence (card heading) | Content: `input-question.exception1-*` (v2, and v3 for the first criterion). The projection copies it in `_closure_question_reasons` → `record_input_fact`. |
| Which questions are named | Content: the declaring blocks in `rule.form1040-line16` v9 and `rule.selected-preferential-base` v12 (ADR 0086 names). The projection walks them from each field. |
| "An answer is recorded here." | Page (`questionGroupStatusText`). It is chosen from the scope `status` that the projection's `_question_group_catalog` (`answer_status`) records: current, stale or unanswered. |
| Code heading, field "blocked" explanation, "What to do: Add or confirm the missing information." | Page (`BLOCKED_CODE_COPY`) and form-field content. The page hides all three whenever a line has reasons, which every target field has. |

No current source carries the answer value or a next step:

- `presentation-model.v3` closes `questionGroups[]` and `questionRefs[].scopes[]`
  with `additionalProperties: false`, and the status vocabulary is fixed.
- `input-question.v1` holds only `question`.
- The four Exception 1 fact types are plain `{yes, no}` enums with no value
  descriptions. A new fact-type version would unpin every recorded answer.
- `family-block-explanation.v1` (ADR 0088) can only be keyed to a
  source-family member-validation block code.
- Rule `wording` is the ADR 0076 reader contract for per-subject selection
  reads.

The answer is in the saved model only as a bare input node value in the
explanation graph, which has no fact id and no link to the question. A
displayed answer would also need a declared reading: line6b-reason Decision 8
shows that a `no-...` fact's value and the filer's yes/no differ by question
wording. Showing the raw value would be wrong for half the published
questions.

## 2. The design (smallest that meets both parts)

**A new content citizen, `answer-explanation.v1`.** It maps one
`(fact_type pin, value)` pair to one plain sentence, and is admitted by
`artifact-package.v45`. The projection shows the sentence as an extra, unlinked
reason beside the linked question in one case: a blocked field's question walk
records the declared input question for a fact, and that fact has exactly one
current answer with that value. This is the ADR 0088 pattern on the same
`presentation-model.v3`, and the page is unchanged.

- Unanswered and stale answers, and values with no declared sentence, are
  unchanged.
- A bare fact-type name in `missing` gets the sentence only when exactly one
  fact of that type has such an answer.

Core v109 adds four citizens, one for each criterion answered no:

| Criterion (answered no) | Declared sentence |
| --- | --- |
| C1 only-box2a-capital-gains | You answered no to the question about capital gains and sales other than box 2a of Form 1099-DIV, so you must file Schedule D. If that is wrong, change your answer. If it is right, record each sale you must report; if you have no sale to record, this calculation does not cover your return. |
| C2 no-capital-losses | You answered no to the question about capital losses, so you must file Schedule D. If that is wrong, change your answer. If it is right, record each sale you must report; if you have no sale to record, this calculation does not cover your return. |
| C3 no-qof-deferral | You answered no to the question about deferring a gain in a qualified opportunity fund, so you must file Form 8949 and Schedule D. If that is wrong, change your answer. If it is right, this calculation does not cover your return. |
| C4 no-boxes-2b-2c-2d | You answered no to the question about boxes 2b, 2c and 2d of Form 1099-DIV, so you must file Schedule D. If that is wrong, change your answer. If it is right, this calculation does not cover your return. |

Each sentence:

- states the answer the filer gave and what it means;
- tells a filer with a wrong answer to change it;
- gives the true next step when the answer is right: record each sale for C1
  and C2, and for C3 and C4, which a sale cannot cure, says the return is not
  covered.

The sentences are sorted after the "Is it true that…" questions, so every
existing reason keeps its index.

The drawn result on `fails/single/03` (C1 and C2 answered no), on each of the
28 fields:

```
This line has no result.
Why:
- See the question and affected lines above
- See the question and affected lines above
- You answered no to the question about capital gains and sales other than box 2a ... this calculation does not cover your return.
- You answered no to the question about capital losses, so you must file Schedule D. ... this calculation does not cover your return.
```

### Alternatives

| Alternative | Why not the smallest |
| --- | --- |
| B. Show the answer and the sentence once, in the question card | Needs the same new citizen plus `presentation-model.v4` (a group-level answer field), a page change, and a v3/v4 reader. Every saved page's schema moves. It meets "where the page asks" most literally. It is the owner's alternative in the ADR draft. |
| C. New `input-question` versions carrying conditional guidance ("if you answer no…") | Content only, with no ADR. It meets the next step but cannot show the answer the filer gave. It also lengthens a question that is already long. |
| D. An `explanation` on a rule's `block` (rule-artifact v18) | Also a schema successor. A sentence per block cannot express "this answer" without one tree leaf per subset, so each of the 15 leaves × 2 rules would need composite text. |
| E. A sentence table in the projection or page | ADR 0088 rejected this: tax wording would sit outside package manifests and validation. |

## 3. Law check (2025 instructions)

Sources are the local copies of the 2025 IRS instructions used by
line16-names: Form 1040, SHA-256 `482e9c48…`; Schedule D, `650643a6…`;
Form 8949, `f077991c…`. Page numbers are PDF page indexes.

| Clause | Instruction text |
| --- | --- |
| "so you must file Schedule D" (C1, C2, C4) | 1040, line 7a (p31): "If you sold a capital asset, such as a stock, bond, or digital asset, you must complete and attach Form 8949 and Schedule D. Exception 1. You don't have to file Form 8949 or Schedule D if you aren't deferring any capital gain by investing in a qualified opportunity fund and both of the following apply. 1. You have no capital losses, and your only capital gains are capital gain distributions from Form(s) 1099-DIV, box 2a (or substitute statements); and 2. None of the Form(s) 1099-DIV (or substitute statements) have an amount in box 2b (unrecaptured section 1250 gain), box 2c (section 1202 gain), or box 2d (collectibles (28%) gain)." The next paragraph: "Exception 2. You must file Schedule D but generally don't have to file Form 8949 if Exception 1 doesn't apply, …" A no on any criterion means Exception 1 does not apply, and ADR-0050's checked conclusion is then yes. |
| "so you must file Form 8949 and Schedule D" (C3) | 1040, line 7a (p31, p33): Exception 2 is limited to filers who "aren't deferring any capital gain by investing in a qualified opportunity fund". Form 8949 instructions (p4): "Caution: Exception 2 is not available for the election to defer eligible gain by investing in a QOF. Taxpayers who elect to defer eligible gain must report the details of each investment in a QOF on Form 8949 …"; and (p12): "Report the deferral of the eligible gain on its own row of Form 8949". |
| "record each sale you must report" (C1, C2) | 1040, line 7a (p31): "If you sold a capital asset … you must complete and attach Form 8949 and Schedule D." The C1 question itself counts "a sale … that you must report on Form 8949 or Schedule D". |
| C2 and other non-sale sources | Schedule D (p1): "Use Schedule D: … To report a gain or loss from a partnership, S corporation, estate, or trust; … To report a capital loss carryover from 2024 to 2025." A loss or gain can make Schedule D required without any 2025 sale. |
| C4 | Schedule D (p2): "If there is an amount in box 2b, include that amount on line 11 of the Unrecaptured Section 1250 Gain Worksheet … if you complete line 19 of Schedule D. If there is an amount in box 2c, see Exclusion of Gain on Qualified Small Business (QSB) Stock, later. If there is an amount in box 2d, include that amount on line 4 of the 28% Rate Gain Worksheet … if you complete line 18 of Schedule D." (p8): a box 2c gain "may be eligible for the section 1202 exclusion … In column (f), enter "Q"". |

The "this calculation does not cover your return" clauses state what the
engine does, not law. Each rests on declared content:

- **No sale recorded** (C1 and C2 with no sale, and all four in this state).
  `rule.form1040-line16` v9 takes the Schedule D route only when a sale count
  is above zero or covered proceeds are positive. With Schedule D required
  and no sale, it can only block (line16-names P0 trace).
- **C3 and C4 after a sale is recorded.** The guard of
  `rule.selected-preferential-base` v12 requires
  `schedule-d-boundary.no-1099da-or-qof`, `no-lines-18-19-sources` and
  `no-other-schedule-d-sources` to be yes. A QOF deferral, a box 2b/2c/2d
  amount (Schedule D lines 18/19), and partnership, Form 2439, 4797, 6252 or
  other sources therefore stay outside the route.

"Record each sale" is the next step, not a promise that the return will then
compute. A recorded sale can still meet a later boundary question.

## 5. Stop: owner decisions needed

The design adds a schema (`answer-explanation.v1`, `artifact-package.v45`), a
package-validation contract, and a projection rule. That is a contract no
accepted ADR covers, so this P0 stops with [adr-draft.md](adr-draft.md):

1. **Accept the contract** — a declared explanation per (fact type, answer
   value), shown when that answer holds up a line — or reject it.
2. **Where the answer shows.** Option A, recommended as the smallest: in each
   blocked line's "Why:" list beside the link, which is 28 lines on a target
   return, on v3 with the page unchanged. Option B: once in the question card,
   which takes presentation-model v4 and a page change. The plan's "where the
   page asks" reads most literally as B.
3. **The four sentences.** They run three short sentences each, against
   sale-explanation-wording's two-sentence bar. With two or more failures,
   the C1 and C2 next steps repeat.
