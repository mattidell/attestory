release and registry authorize a real `live_coordinate_run`. The coordinator

the existing citation-walk page renders it. Question wording comes from
adopted question citizens, not the evidence script. Actual correction and
retraction acts determine source currency. A hypothetical answer that changes
the block is not evidence that the answer is truthful.

schema, engine, projection, page and kernel changes; Path B, lines 18/19 and
the code-L question. The ten pinned cases and every computing neighbour
must remain unchanged. No agent was spawned and nothing was pushed.

Run `track0.py` with `names`, `boundary`, `late`, `neighbours` or `page`,
followed by the scratch core descriptor. `page` accepts an optional output
directory. `replay` additionally takes the saved part file. `assess-names`
and `assess-boundary` re-evaluate saved observations without another live
run; the ordinary `names` and `boundary` commands include those assessments.
