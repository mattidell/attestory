### Form 1099-B Box 4 Question and Rules Reading It on Core v82

- **Question citizen:** `tax.us.2025.input-question.f1099b-statement-box4-withholding-reported.v1`
  - Text: *"For each Form 1099-B or substitute statement you recorded a sale from, does it show federal income tax withheld in box 4?"*
  - Fact type: `tax.us.2025.f1099b.statement-box4-withholding-reported` (keys: `statement`, `tax-year`; values: `"yes"`, `"no"`).
- **Rule reading it:** Exactly one rule reads this question on core v82: `tax.us.2025.rule.form1040-line25b.v6`.
  - In `when`: `require_paired` on `key: "statement"` between the 8 sale transaction member fact types and `f1099b.statement-box4-withholding-reported`.
  - In `value`: a `choose` condition checks whether any sale count > 0 and `not collect_categorical_all_equal == "no"`. If any statement answered `"yes"`, it executes `then: { "op": "block", "code": "DEPENDENCY_ABSENT" }`. If all answered `"no"` (or if no sales exist), it proceeds to `else` and sums the five other 1099 subtotals.
- **Does any Form 1099-B record carry a box 4 amount today?**
  **No.** Neither the statement entities, nor the 8 transaction member fact types, nor any companion fact type carries a box 4 amount field on core v82. Only the determinable categorical yes/no fact type exists.

### Key Findings from Core v82 Probes

1. **Why v82 blocks on Box 4:** `rule.form1040-line25b.v6` executes `then: { "op": "block", "code": "DEPENDENCY_ABSENT" }` whenever any Form 1099-B statement answers "yes". Because this block occurs in `value` without a missing symbol array, the presentation model produces an empty explanation sentence (`[]`), giving the filer no indication of how to resolve it.
2. **Cascading line failure:** Blocking line 25b cascades to line 25d (total withholding), line 33 (total payments), line 34 (refund), and line 37 (amount owed). The filer cannot complete or file their return.
3. **Collateral blocking of other 1099 withholding:** When box 4 is "yes" on a Form 1099-B, valid withholding already recorded on Form 1099-INT and Form 1099-DIV is also completely blocked from line 25b (`b4_beside_int_div`).
4. **Surplus answers do not break returns:** When a statement's sales are removed (`b4_statement_removed`), `require_paired` inspects the statement key of current income rows. With zero income rows on that statement, pairing is vacuously satisfied, sale counts are 0, and line 25b computes the `else` branch cleanly.

## 4. Design for Successor Core v83

The fix is a **pure content-only fix** across 5 citizen artifacts. It requires **no engine change, no schema change, no new expression operation, and no recording-surface change**.

### 1. Where the Box 4 Amount is Recorded
A new statement-level determinable fact type is introduced in a dedicated bundle:
- **Bundle citizen:** `tax.us.2025.f1099b.box4.v1` (`f1099b-box4.bundle.json`, schema `bundle.v2`).
- **Fact type:** `tax.us.2025.f1099b.statement-box4-withholding` (schema `fact-type.v2`).
  - `identity_keys`: `statement` (entity: `tax.us.f1099b-statement`), `tax-year` (literal: `"2025"`).
  - `nature`: `determinable`.
  - `value_schema`: `{"type": "number", "minimum": 0}`.
  - Matches the identity keys of the existing `statement-box4-withholding-reported` fact type.

### 2. What the Box 4 Question Becomes
The binary yes/no question is replaced by a direct numeric amount question matching the other 1099 withholding questions:
- **Citizen:** `tax.us.2025.input-question.f1099b-box4.v1` (`input-question.f1099b-box4.v1.json`, schema `input-question.v1`).
- **Question text:** *"Enter the federal income tax withheld in box 4 of each Form 1099-B or substitute statement you recorded a sale from. If box 4 is blank, enter $0."*
- **Targets:** `tax.us.2025.f1099b.statement-box4-withholding`.

### 3. Source Family
To conform to `package_validation.py` and `rule-artifact.v15` requirements for `collect`:
- **Family citizen:** `tax.us.2025.f1099b.b4.v1` (`family.f1099b-b4.json`, schema `source-family.v1`).
  - `member_predicate`: `tax.us.2025.f1099b.statement-box4-withholding`.
  - `authorizes_subtotal`: `tax.us.2025.payments.line25b`.

### 4. How Line 25b Pairs and Sums Box 4

### 5. Form Field Presentation
- **Citizen:** `tax.us.2025.form1040.line-25b.v5` (`form1040.line-25b.form-field.v5.json`, schema `form-field.v3`).
- Updates `description` and `published_value.explain` to include Form 1099-B box 4 backup withholding.
- Retires the temporary refusal sentence from `blocked.explain`:
  > *"It is also blocked while a recorded Form 1099-B statement has no answer about box 4, and when a Form 1099-B shows federal income tax withheld in box 4: this return does not add Form 1099-B withholding yet."*
  becomes:
  > *"Form 1040 line 25b is blocked because an input it needs is missing or not yet closed. It is also blocked while a recorded Form 1099-B statement has no answer about box 4."*

### 6. True Reason Each Blocked Line Gives
When a statement with sales is missing its box 4 withholding answer:
`require_paired` fails on `when`, blocking line 25b with `DEPENDENCY_ABSENT` naming `tax.us.2025.f1099b.statement-box4-withholding`.
The presentation model resolves this dependency to `input-question.f1099b-box4.v1` and emits the true reason sentence:
> **"Enter the federal income tax withheld in box 4 of each Form 1099-B or substitute statement you recorded a sale from. If box 4 is blank, enter $0."**

Lines 33, 34, and 37 block downstream and cite line 25b's missing input.
