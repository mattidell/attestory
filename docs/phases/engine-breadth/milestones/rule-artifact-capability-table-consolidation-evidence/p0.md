## 3. Capability Table Design (`packages/derivation/schema_capabilities.py`)

Pure standard-library module (`dataclasses`, `typing`) with zero package imports
so every module in `packages/derivation/` can import it without circular
dependencies.

### Dataclass Schemas & Columns

1. **`RuleArtifactCapabilities`** (`17` rows: `rule-artifact.v1`–`v17`)
   - `schema: str`
   - `uses_v2_record: bool` (`v2`–`v17`)
   - `declared_refs_outside_requires: bool` (`v3`–`v17`)
   - `field_ref_validation: Literal["none", "top_level", "expression_nodes"]` (`"none"` for `v1`–`v6`, `"top_level"` for `v7`–`v8`, `"expression_nodes"` for `v9`–`v17`)
   - `declared_line2b_v9_selection: bool` (`v9` only)
   - `supports_link_coverage: bool` (`v10`–`v17`)
   - `supports_subject_declaration: bool` (`v11`–`v17`)
   - `subject_optional: bool` (`v13`–`v17`)
   - `supports_link_count: bool` (`v12`–`v17`)
   - `supports_reader_role: bool` (`v12`–`v17`)
   - `supports_shared_key_count: bool` (`v13`–`v17`)
   - `supports_v13_selection: bool` (`v13`–`v17`)
   - `supports_require_paired: bool` (`v15`–`v17`)
   - `validation_graph_participant: bool` (`v1`–`v11`; see Drift Finding 4)

2. **`AttachmentRuleCapabilities`** (`10` rows: `attachment-rule.v1`–`v6`, `v8`, `v10`–`v12`)
   - `schema: str`
   - `executable_and_validated: bool` (`v1`–`v6`, `v8`, `v11`, `v12`; `False` for `v10` unless Decision 2 unifies)
   - `projection_supported: bool` (`True` for all 10 published versions)
   - `legacy_single_row_set: bool` (`v1` only)
   - `uses_row_sets: bool` (`v2`–`v6`, `v8`, `v10`–`v12`)
   - `supports_adjustment_rows: bool` (`v6`, `v8`, `v10`, `v11`; `False` for `v1`–`v5`, `v12`)
   - `eager_adjustment_requires: bool` (`v6`, `v8` only — **must exclude `v11`**, whose `exclusive_presence` selection paths omit top-level `adjustment["subtotal_symbol"]` and must not wait for unselected path subtotals in `_Run._requires`)
   - `projection_reads_row_sets: bool` (`v6`, `v8`, `v10`, `v11`, `v12`; `False` for `v1`–`v5` where projection uses `_raw_leaves`)
   - `bfs_reachability_edges: bool` (`v6`, `v8`, `v11`, `v12`; `False` for `v1`–`v5`, `v10` to preserve historical `rule_scoped_closure` digests)
   - `supports_exclusive_adjustment_selection: bool` (`v11` only)
   - `supports_conditional_and_limited_parts: bool` (`v12` only)

3. **`ArtifactPackageCapabilities`** (`43` rows: `artifact-package.v1`–`v26`, `v28`–`v44`)
