## 2. Mechanism

A selection path's `requires` must equal its `ref` names and undeclared
collect-family names (`packages/derivation/package_validation.py`,
`_iter_selection_dependency_names` and the equality at the
`RULE_SELECTION_DEPENDENCIES_INVALID` check). ADR 0077 Part 4, Validation,
states that equality.

The runner then waits until every `requires` name is in `symbols`
(`packages/derivation/runner.py`, `_attempt_v13_selection`, the missing
list built from `declaration.get("requires")`). Presence is decided from
current sources before that wait.

Marshal never binds a keyed collect member into that symbol. Family member
fact types are `collect_names` (`packages/derivation/live.py`, taken from
each family's `member_predicate`). Current findings of those types become
`sources`. The single-symbol fallback skips any type id in `collect_names`
(`packages/derivation/marshal.py`). A later publication under the same id
does occupy `symbols` (`runner.py` stores the published value on the
symbol).

The stand-in works because it publishes 0 under the member fact id, which
puts the name in `symbols` and satisfies the wait. The collect still reads
`sources`, so line 25b and the subtotal follow the recorded amounts. The
explanation walk of the member id is the 0.

The two-path minimum is `rule-artifact.v15` `selection.paths.minItems` 2,
and ADR 0077 Part 4, Shape: "paths has at least two paths." The inert path
exists to fill that minimum. Exclusive presence is already decided from
activity; the default is the closed-empty branch.

## 3. Design

Smallest engine change: stop treating a collect of the path's own activity
family as a symbol dependency. Gate it by adopted package, the same way
core v75 and v76 gate their runner switches in `packages/tax/loader.py`.

- New switch `selection_collect_satisfied_by_family`, true from
  `core-calculations` v86.
- When the switch is on, `_iter_selection_dependency_names` does not yield
  a collect-family name whose `(name, source_set)` pair is the path's
  `source_nonempty` activity family and member. `ref` names stay in
  `requires`. Closed-family counts stay excluded as they are today.
- The runner does not need a second wait. Once `requires` no longer lists
  the collect name, the selected path evaluates. Collect still reads
  `sources`.
- Marshal stays as it is. Binding keyed assertions into a single symbol
  would disagree when two amounts are current, and would make a later
  `ref` of the member id read one amount instead of remaining a family
  collect.

**Two-path minimum.** Drop it, in a new schema version
`rule-artifact.v16` (`minItems` 1). Exclusive presence with one path and a
default is "this activity, else closed-empty." A two-real-path rule such
as line 2b v8 keeps two paths. The prototype lowered `minItems` on a
temporary copy of v15 only so the scratch core could retire the inert
path; production must publish v16. Article 9 forbids editing published
v15.

**Scratch core v86.** Built outside the repository by `prototype.py`.
Removes `rule.f1099b-b4-amount-symbol`. Replaces the subtotal with v2: one
path `amounts`, empty `requires`, empty `pins`, the same collect, the same
default 0. `prototype-build.json` records the successor. Loader companions
are copied from v85 for the run (`loader_from`).

## 5. ADR verdict

This changes a rule-language contract. ADR 0077 Part 4 currently requires
collect-family names in path `requires`, and requires at least two paths.
Draft: `docs/adr/0085-selection-collect-by-family.md`, status `proposed`.

It is not a marshal change and not a new expression operator.

## 6. Recommendation

Track 1 should:

1. Land the switch and the validation skip, from core v86, as in
   `engine.patch`.
2. Publish `rule-artifact.v16` with `paths.minItems` 1 (copy of v15 plus
   that change), admit it on a package successor, and thread `v16` through
   the existing `rule-artifact.v15` enumerations in derivation. Do not
   edit published v15.
3. Ship core v86: retire `rule.f1099b-b4-amount-symbol`, replace the
   subtotal with the one-path v2, add the v86 companion-declaration
   loader entry copied from v85.
4. Accept ADR 0085 before the PR goes ready.

The inert fact type in `f1099b-box4.bundle.json` can remain unused on v86
or leave with a bundle successor; that is content cleanup, not the engine
change.
