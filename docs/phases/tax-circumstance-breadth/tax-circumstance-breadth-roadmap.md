home borrowing, calculates the bounded interest treatment, and saves an

Plan a bounded extension of the existing Form 1098 route. Let a person identify

The existing route already connects Form 1098 to the deduction calculation,
but asks for tax-shaped confirmations such as acquisition-debt use. That makes
this a useful first application: an existing consumer can test the translation,
and the prior student-loan work supplies concrete mechanisms to examine.

Investigate the bounded case before selecting the implementation. Systematic
handling of assumptions belongs in that investigation wherever the case needs
it; a separate general assumption framework is not a prerequisite by decree.
