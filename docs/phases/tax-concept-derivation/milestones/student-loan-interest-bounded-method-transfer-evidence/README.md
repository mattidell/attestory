## The boundary this evidence sits inside

The method was exercised through **real engine machinery** — the real
coordinator, admission, evaluation, lifecycle and durable-pin paths, over the
production Form 1098-E box-1 source and its closure-authorized subtotal — with
**disposable candidate artifacts**: fact types, rules, citation citizens, package
members and adoption material sealed into a synthetic release and **never adopted
into the production package**.

So it establishes that the method **can** work. It does **not** establish that the
production application performs this translation today.
