### Six cases

Use one small two-report fixture, isolated per run. Report A Box 1 is $8,000,
Box 2 $240,000; B Box 1 $3,000, Box 2 $220,000. Both Box 3 observations are
2019-03-04 and Box 9 is 1. The person recognizes the same original borrowing,
links each exact report, supplies a $250,000 annual ceiling and says no other
secured borrowing on either home. All nine report-local answers are supplied
consistently; filing status is single. Use obviously synthetic `demo.*` IDs.

| Case | Sole change from baseline | Required observation |
| --- | --- | --- |
| Positive baseline | None | One line8a publication of $11,000; each report result depends on its own source/ordinary answers. Common balance is compared once, not summed from snapshots. |
| B contrary local payment | B's paid-interest answer becomes the existing partial/others-paid outcome | B reads B's actual answer, not A's; the bounded combined full-interest result cannot publish. Do not produce a favorable subset. |
| B membership missing | Omit B's affirmative membership assertion only | No favorable partial sum or singleton fallback; missing relationship blocks the combined result. |
| Principal contradicts ceiling | B's Box 2 becomes $270,000 | Conflict/unresolved, not an automatic raised ceiling or a favorable result. |
| Loose upper bound | Ceiling becomes $900,000, both Box 2 observations unchanged | Insufficient support under the modeled $750,000 limit, not proof that actual debt exceeded it; no favorable amount. |
| Origination disagreement | B's Box 3 becomes 2020-03-04 | Named conflict/unresolved; neither select one date nor silently inherit A's category. |

Keep the incumbent on-or-before-1987-10-13 exclusion and conservative
$750,000/$375,000 parameter boundary. Do not add the higher pre-2017 limit.
The current package's unrelated facts/defaults may be reused, but inventory
them honestly. No Box 2 snapshot may stand in for an annual ceiling. Preserve

shared-answer intermediate and its producer-removal control are omitted.
