# Archived Milestone Artifacts — 2026-08-02

This archive separates completed execution material from the repository's
active product and process record. It contains historical charters, reviews,
prototype rounds, completed milestone plans from closed phases, superseded
process proposals, and completed legibility-audit reports.

These files remain available as evidence and drafting history under
`AGENTS.md`, "Shared invariants" (Archives are never authority). Current
authority and curated history live in:

- `docs/governance/` for the governance set;
- `docs/adr/` for product contracts and their status;
- `docs/milestone-retrospectives/` for distilled milestone history;
- `docs/phases/` for active phase direction and summaries;
- `AGENTS.md`, `PROJECT_PLANNING.md`, and `docs/roles/` for current process.

The original topology is preserved beneath this directory so historical links
and relationships remain understandable. Concrete repository references were
updated when the files moved. Do not restore an archived charter or plan as an
active instruction without re-evaluating it against the current process and
repository state.
