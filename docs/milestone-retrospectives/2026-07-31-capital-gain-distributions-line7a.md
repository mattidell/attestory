# Retrospective — Capital-Gain Distributions and Form 1040 Line 7a

- Merged: pending closing PR

## What differed from the plan

Official 2025 instructions corrected the initial box-2a-plus-Schedule-D shape
before production: the bounded class reports directly on line 7a and requires
authority that Schedule D is not required. Track 3 then stopped at a missing
line-7b field/package successor; the prerequisite became its own reviewed unit
rather than being hidden inside presentation work.

The first citation-repair charter also stopped cleanly. Its universal
rule-to-field citation requirement reached legacy rules with no `citations`
declaration, so the charter was narrowed before implementation to the generic
invariant supported by current declared-citation paths.

## What it cost

The rival round selected explicit component authority over a thinner
conclusion-level declaration. That bought correctable, explainable Exception-1
eligibility at the cost of four contribution facts, longer correction
cascades, two prototype repairs, and additional production lifecycle cases.

Review cost concentrated at integration seams: typed inapplicability, versioned
release routes, deterministic fixtures, line-7b package resolution, fixed
categorical values, and exact citation identity. Findings-only charters kept
those repairs bounded, while crediting unchanged measurements avoided repeating
the broad Track-2 and Track-3 reviews.

## Follow-ups

- Select Schedule D only when its transaction sources, completeness, loss, and
  attachment boundary can be chartered together.
- Revisit C1–C4 when another positive capital-gain source enters scope; that is
  the trigger to test whether Exception-1 authority needs a successor.
- Migrate legacy no-`citations` rules only through an explicit versioned
  contract/package unit; compatibility alone is not evidence of a citation
  chain.
- Keep the separate interest and infrastructure triggers in the milestone
  deferral ledger; age alone does not reactivate them.

## What should change in the next plan

Inspect official routing instructions before pairing a source with a schedule.
Inventory resolved form fields and package membership before presentation
starts, and charter prerequisites separately. State generic invariants with
their legacy boundary up front. For focused repairs, name the evidence that
remains credited and require valid-output identity when the repair should be
fail-closed only.
