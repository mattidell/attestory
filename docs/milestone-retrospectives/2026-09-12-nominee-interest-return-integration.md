# Retrospective — Nominee Interest Return Integration

Closed 2026-09-12. The third production stage of nominee-interest support: a
current ordinary allocation now reaches one bounded taxable-interest result
and an honest Schedule B Part I account on `package.core-calculations` v38.
The new path subtracts exactly once. Legacy-only workspaces keep the old
subtotal; a live legacy amount together with a current new allocation refuses
rather than converting or double-subtracting. Ambiguous nominee identities
return a typed pre-run `NOMINEE_IDENTITY` refusal with no run id, output, or
start record. Ordinary commas remain valid.

Not done, deliberately: Form 8815 / §135 and wider 2025 taxable-interest
coverage; information-return filing; a general fact-id repair; I4
causal-block explanation; UI.

## Decisions worth carrying forward

The arithmetic is owned by declared citizens. Package v38 uses a distinct
nominee aggregate producer and a declared four-state line-2b selection rather
than an undeclared aggregate or a runtime rewrite of published rule content.
This is deliberately bounded to the nominee legacy/new transition; it is not
a repository-wide presence operator.

Schedule B form itemization and report-group explanation are different
structures. `citationGroups.parts` remain form itemization.
`provenanceGroups` carry the report-to-allocation explanation without creating
fake Schedule B subsections.

## Reusable lessons

- A passing numeric case does not establish that the adopted rule citizen owns
  the calculation. Tests must compare the declared expression and producer to
  the path the runner actually executes.
- A general-looking schema field is not a contract until validation and every
  consumer enforce its identity, cardinality, and relationship rules.
- Reader evidence must inspect the durable form-field or presentation model.
  In-memory publications and internal rule notes do not establish what a user
  can see.

## Follow-ups

- **I4 causal-block explanation.** A blocked Schedule B still does not name
  which report group caused the dependent aggregate to block. Reactivate
  when a reader must distinguish report-local cause on the blocked path.
- **Form 8815 / §135 and wider interest.** Still unmodeled. Reactivate when
  a selected case needs those categories.
- **General fact-id injectivity.** The kernel rendering remains
  non-injective; this milestone only refuses delimiter-shaped nominee
  identities before start-record. Reactivate for a kernel identity repair.
- **Information-return filing.** Unchanged exclusion.

## What should change in the next plan

Charter the declared producer and the expression the production path will
evaluate, not only the numeric cases. A green live battery is not proof
that the adopted citizen owns the result. When a reader-facing boundary
matters, measure the published form-field or presentation contract, not an
internal note.
