## What happened

The milestone opened to make Form 1040 line 16 name the same eight
questions as the 23 other blocked fields on a return where Schedule D is
required and no sale is recorded. P0 found the parked protected case
(a personal-item loss on Form 8949) must keep its four names, since no
Exception 1 answer can truthfully clear it, and prototyped a narrow
eight-name successor.

Track 0 then asked whether each name shown gives the filer a way
forward. On the target returns, 49 of 56 name/return pairs did not: no
truthful answer moved line 16. That was true of v94's own four names and
of the eight the other fields already showed. The foreman replaced the
milestone's goal: in that state both rules name exactly the Exception 1
criteria whose current answer fails, which are the answers that make
Schedule D required. Track 0b built it as a fifteen-leaf choose over the
four criteria in each rule and closed it. Its replay took six times as
long as P0's; Track 1 timed both cores on the same lists first (ratio
0.99), so the slow run was machine load. The fresh review was ready with
no blocking finding.

Dispatch: Codex (gpt-6.1-sol). One builder thread across P0, Track 0 and
Track 0b (high) and Track 1 (medium); one fresh reviewer thread (high).
Builder turns read 13.6-77M input tokens, 99% cached; the review read
2.9M.

## What worked

- A Track 0 item that tested each name as a way forward, answer by
  answer, through the act list. It overturned a goal ("match the other
  fields") that every compatibility check had passed.
- A speed gate before publishing, on the same lists back to back. It
  turned an alarming wall time into a measured non-issue in minutes.
- The strict classifier, chartered from P0 on after box4-no-prompt's
  review.

## What to change

- "Consistent with the neighbouring fields" is not a goal when the
  neighbours were never checked against the filer's way forward. Charter
  the way-forward test in P0, not Track 0.
- State a replay's retained surface whenever claiming nothing changed;
  the pin is not the whole page (L16-R1).
- A full-replay wall time is not a speed measurement. Compare cores on
  the same lists, interleaved, before concluding anything.
